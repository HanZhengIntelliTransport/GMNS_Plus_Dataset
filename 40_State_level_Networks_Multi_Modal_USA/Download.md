# 📥 U.S. State-Level Network Data Download

This repository provides access to standardized transportation network datasets for **all 50 U.S. states and the District of Columbia**.

## 🔗 Download Link

You can download the complete dataset from the following Dropbox folder:

👉 [Download Dataset](https://www.dropbox.com/scl/fo/08v9timxtaitmx2wv4rkc/ACML24HH5_YD7THJFpYZutU?rlkey=l0ut2ryzzb3stmd8anlf6w2sq&dl=0)

## 📁 Content Description

The folder contains:
- 51 subfolders (one for each U.S. state + DC)
- Each folder includes GMNS-compatible transportation network files (`node.csv`, `link.csv`, etc.)
- Data is structured for ease of use in network modeling and analysis tasks

## 📌 Notes
